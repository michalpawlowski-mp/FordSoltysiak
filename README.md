# Ford Sołtysiak – Strona wizytówka

Strona internetowa dla serwisu samochodowego **FORD Sołtysiak** z Bydgoszczy. Specjalizacja w diagnostyce i naprawach samochodów marki Ford.

## 📌 Status projektu

Projekt dla lokalnego biznesu. Na ten moment wdrożony na Vercel. W przyszłości planowana migracja na własną domenę.

## 🛠️ Technologie

- React + Vite
- TypeScript
- Tailwind CSS
- Framer Motion (animacje)

## 🔗 Live Demo

**[Otwórz stronę →](https://fordsoltysiak.vercel.app)**

## 📄 Główne sekcje

- Hero z animowanym tłem i opiniami klientów
- Sekcja usług (8 kart usług)
- Zalety serwisu / atuty firmy
- Dane kontaktowe, godziny otwarcia oraz mapa Google
- Pełna responsywność + smooth animacje przy scrollowaniu
